Figma AI "Make Design"：生成式 UI 的起点 vs 人工接管点

Figma AI "Make Design": Where Generation Ends and the Human Takes Over

今天拆什么：Figma AI 的 Make Design —— 在 prompt 框里写一句话（"一个 SaaS 仪表盘，有侧边栏和数据卡片"），Figma 直接在画布上生成一屏完整的起始设计（frame）。

What we're tearing down: Figma AI's Make Design — type one sentence in a prompt box ("a SaaS dashboard with a sidebar and data cards") and Figma generates a complete starting frame right on the canvas.

①Trust calibration 做得怎么样？How is trust calibrated?

它几乎完全不用数字置信度 —— 策略是"不承诺，交付草稿"：

  • 生成物直接落在画布上，但姿态是半成品：你能一眼看到 layer 命名、auto layout 结构都很粗糙 —— 这种"未完成感"本身就是 calibration。AI 没说自己做对了，视觉就先告诉你"别全信"。
  • 深层取舍：越像成品的生成物，越容易给人虚假的安全感。Figma 让生成物待在画布的草稿姿态（provisional by default），而不是开一个新页面假装这是"答案"。
  • 弱点：没有显式表达"这部分我没把握" —— 所有区域看起来同样确定，calibration 只靠"它是个草稿"这一层。

It uses almost no numeric confidence — the strategy is "make no promise, deliver a draft":

  • The generated frame lands on the canvas but arrives visibly unfinished: rough layer names, coarse auto-layout structure — this "draft-ness" is the calibration. The AI never claims to be right; the visuals say "don't fully trust this" first.
  • The deeper trade-off: the more finished a generated artifact looks, the more false safety it creates. Figma keeps the output in a draft posture (provisional by default) instead of opening a new page pretending it's "the answer".
  • The weakness: there's no explicit way to say "I'm unsure about this part" — every region looks equally certain; calibration rests entirely on the "it's a draft" layer.

②Graceful degradation 在哪？Where is graceful degradation?

  • 失败时：报错 + 重新生成。不玩花样，也不替用户硬编一个。
  • prompt 太模糊时：降级为一个平庸但完整的架子 —— "有总比没有好"的起点，而不是沉默。核心任务（设计师本来就要画这一屏）从不断裂：最差情况就是今天没省下那 20 分钟。
  • 缺口：质量差时没有"降级成线框"这类显式策略，只能靠用户自己删了重来。
  • On failure: an error + regenerate. No gimmicks, no forced improvisation.
  • On a vague prompt: it degrades to a mediocre-but-complete scaffold — a "better than nothing" starting point rather than silence. The core task (the designer was going to draw this screen anyway) never breaks: the worst case is simply not saving those 20 minutes today.
  • The gap: no explicit "degrade to wireframe" strategy for poor-quality output — the user must delete and redo manually.

③人有没有 override 的机会？Can the human override?

  • 这是整个设计的点睛之笔：生成物是原生 Figma 图层 —— override 发生在人的主场，不用学任何新交互。
  • 接管点极其明确：prompt 描述意图 → AI 搭架子 → 从落到画布那一刻起，全部决策权归人（布局、组件、token、规范），没有交接仪式，因为输出本来就待在你的工具里。
  • 代价阶梯清晰：追加 prompt 微调 < 重新生成 < 人工重做。接受 = 直接开始改，拒绝 = 删掉或重新 prompt —— 都是一步操作。
  • This is the masterstroke of the whole design: the output is native Figma layers — the override happens on the human's home turf, with no new interaction to learn.
  • The handoff point is crystal clear: prompt describes intent → AI builds the scaffold → the moment it lands on the canvas, all decision-making belongs to the human (layout, components, tokens, specs). No handoff ceremony, because the output already lives in your tools.
  • A clean cost ladder: refine with a follow-up prompt < regenerate < redo by hand. Accepting means "start editing"; rejecting means "delete or re-prompt" — both are one action.

设计师 takeaway：AI 生成式 UI 的最佳 handoff 是"把输出放进用户已有的工作流"，而不是"给 AI 造一个新编辑器" —— 接管点越明确（"从这一秒起，全是你的"），人越敢用。

Designer takeaway: the best handoff for AI-generated UI is "put the output inside the user's existing workflow", not "build the AI a new editor" — the clearer the handoff point ("from this second on, it's all yours"), the more confidently people use it.

🎙️ 面试怎么讲：Figma Make Design 的 trust calibration 靠的是"交付草稿"而不是置信度分数 —— 生成物故意以半成品姿态落在画布上，让不确定性可见；override 之所以低成本，是因为输出是原生图层、人在自己的主场接管。我在 AI Hub 里会沿用同一逻辑：AI 输出默认 provisional，但要用人已有的界面承载，别让用户为了改 AI 的东西再学一套操作。

🎙️ How to say it in an interview: Figma's Make Design calibrates trust by "delivering a draft" instead of confidence scores — the output lands on the canvas visibly unfinished, making uncertainty visible; override is cheap precisely because the output is native layers and the human takes over on their own turf. I'd apply the same logic in AI Hub: AI output is provisional by default, but it must be carried by interfaces the user already has — never make people learn a new interaction just to fix the AI's output.
