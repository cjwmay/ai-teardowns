Midjourney：四图候选

Midjourney: The 4-Image Grid

今天拆什么：在 Midjourney 输入 prompt 后，AI 不直接给一张"最终答案"，而是先交 2×2 四张候选图；你可以 U1–U4 放大某一张（upscale），或 V1–V4 让某一张"再生变体"（variations）。

What we're tearing down: after a prompt, Midjourney doesn't hand you one "final answer" — it serves a 2×2 grid of four candidates. U1–U4 upscales one (upscale); V1–V4 regenerates variations of one (variations).

①Trust calibration 做得怎么样？How is trust calibrated?

它的策略是用多选项代替单点不确定性。Midjourney 从不告诉你"我对这张图有多确定"（扩散模型本质上也没有置信度分数可报），它把"不确定性"翻译成"多样性"：给你看四个它都认为还不错的可能解，让你用人眼做仲裁。

  • 取舍：它把判断成本转嫁给了用户 —— 你得看四张、挑一张。但换来的是诚实：承认 prompt→图像的映射是一对多的，不假装存在一个"正确"答案。对比 Day 1 的 Copilot（ghost text 用草稿感表达"这只是个猜测"），Midjourney 的表达是"这里有四种猜测"。
  • 更深的一层：U / V 按钮本身就是 calibration 界面 —— U（upscale）="这张对了，继续"（确认）；V（variation）="方向对了但没到"（部分接受）。系统从不让你"整体接受四张"，每个选择都是对 AI 判断的一次显式校准。

Its strategy is replacing single-point uncertainty with multiple options. Midjourney never says "I'm X% sure about this image" (diffusion models have no confidence score to report) — it translates "uncertainty" into "diversity": four plausible solutions, with your eyes as the arbiter.

  • The trade-off: judgment cost shifts to the user — you must scan four images and pick one. What you get in return is honesty: it admits the prompt→image mapping is one-to-many instead of pretending there's a single correct answer. Contrast with Day 1's Copilot (ghost text's "this is just a guess" draft feel); Midjourney says "here are four guesses".
  • One layer deeper: the U / V buttons are the calibration interface — U (upscale) = "this one is right, go on" (confirmation); V (variation) = "right direction, not there yet" (partial acceptance). The system never asks you to "accept all four" — every click is an explicit calibration of the AI's judgment.

②Graceful degradation 在哪？Where is graceful degradation?

  • 失败时降级为"更少的选择"，而不是报错：生成失败或排队中，grid 不会出现，但你能看到进度条和重新 roll（⟳ re-roll）—— 最差情况是"等 + 重来"，核心任务（继续迭代）不断裂。
  • 内容安全拦截时降级成"指导"：prompt 被拒，返回的是"哪条规则拦了你 + 换个说法试试"，而不是一张黑图或沉默 —— 让你带着修改继续。
  • 四图机制本身就是 degradation 设计：单张生成质量不稳定是常态，四张里"至少一张能用"的概率远高于单张 —— 用冗余（redundancy）对冲生成的不确定性。对比 Day 4 的"粒度越小 blast radius 越小"，这里是"选项越多，单次失败越不致命"。
  • Failure degrades to "fewer options", not an error: if generation fails or queues, no grid appears — but you see a progress bar and a ⟳ re-roll. The worst case is "wait + retry"; the core task (keep iterating) never breaks.
  • Safety blocks degrade to guidance: a rejected prompt returns "which rule flagged you + try rephrasing this way" — not a black image or silence — so you can continue with a fix.
  • The four-image mechanism is degradation design in itself: single-image quality is unstable, but "at least one of four is usable" is far more likely — using redundancy to hedge generative uncertainty. Contrast with Day 4's "smaller granularity, smaller blast radius": here it's "more options, less fatal single failures".

③人有没有 override 的机会？Can the human override?

选择本身就是 override，而且带代价阶梯：

  • ① U1–U4 选图 —— "接受这张、放弃其他三张"，AI 给候选、人做最终仲裁，override 成本 = 点一下。
  • ② V1–V4 变体 —— 部分 override：保留这张的构图 / 风格 DNA，只换细节 —— 与 AI 输出同粒度（都是一张图），但比"整批重来"便宜得多。
  • ③ Remix / 重写 prompt 重 roll —— 全量 override：推翻整批四个，从头再来。
  • 关键设计：override 的代价阶梯（选图 < 变体 < 重写 prompt 重跑）与"推翻程度"成正比 —— 小修正便宜、大推翻贵，迭代手感非常顺。呼应 Day 1：override 成本低，人就敢用 AI。

Selection is override — and it comes with a cost ladder:

  • ① U1–U4 pick — "accept this one, drop the other three": the AI proposes, the human arbitrates, at the cost of one click.
  • ② V1–V4 variation — partial override: keep this image's composition/style DNA, swap the details — same granularity as the AI's output (one image), far cheaper than re-rolling the batch.
  • ③ Remix / rewrite prompt & re-roll — full override: discard all four, start over.
  • The key design: the override cost ladder (pick < vary < rewrite & re-run) scales with the degree of rejection — small fixes are cheap, big rejections are expensive, so iteration feels smooth. Echoing Day 1: when overriding is cheap, people dare to use the AI.

设计师 takeaway：当 AI 输出天然不确定、且没有"标准答案"时，别学搜索框"给一个最佳答案"，学 Midjourney"给一组候选让人仲裁"—— 把不确定性做成多样性，把判断权交还给人。对 AI Hub 可迁移：开放式生成（比如 SEO Studio 的标题 / 描述建议）应该一次给 3–4 个版本让人挑，而不是给一个"最优解"让人只能接受或重写。

Designer takeaway: When AI output is inherently uncertain with no "correct answer", don't copy the search box's "one best answer" — copy Midjourney's "a set of candidates for the human to arbitrate": turn uncertainty into diversity and hand judgment back to the person. Transferable to AI Hub: open-ended generation (e.g. SEO Studio's title/description suggestions) should offer 3–4 versions to pick from, not one "optimal" answer the user can only accept or rewrite.

🎙️ 面试怎么讲：Midjourney 不用置信度分数做 trust calibration，而是把不确定性翻译成四个候选、让用户做仲裁 —— U / V 的代价阶梯让"小修正便宜、大推翻贵"。我在 AI Hub 的开放式生成里沿用同一原则：多候选 + 人仲裁，而不是单点最优解。

🎙️ How to say it in an interview: Midjourney doesn't calibrate trust with confidence scores — it translates uncertainty into four candidates and lets the user arbitrate, with a U/V cost ladder that makes small fixes cheap and big rejections expensive. I applied the same principle to open-ended generation in AI Hub: multiple candidates + human arbitration, not a single optimal answer.
